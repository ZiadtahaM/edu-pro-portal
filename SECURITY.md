# Security Policy

## Supported source branch

Security fixes target the current default branch. Do not commit or disclose academic records, credentials, cookies, keys, database URLs, or deployment configuration.

## Reporting a vulnerability

Send a private report to the repository owner that documents the affected path, reproduction steps, impact, and proposed remediation. Coordinate a fix before making vulnerability details public.

## Education-data safeguards

Keep authorization and data access server-enforced, validate input at typed boundaries, and protect runtime configuration through the deployment platform’s secret manager. Review dependency updates and pass quality gates before release.
